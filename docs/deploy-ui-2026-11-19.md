# Memasang pembaruan UI di cPanel

Untuk instalasi yang sebelumnya sudah berada pada versi b466fc2 atau lebih baru, dengan webroot terpisah seperti akun inon1796. Paket ini tidak menambah migrasi database.

Tempel di Terminal cPanel:

```bash
(
  set -e
  cd /home/inon1796/repositories/Sila-DesBeng
  PHP=/opt/alt/php82/usr/bin/php
  WEBROOT=/home/inon1796/public_html/siladesbeng.inovasia.site
  test -d "$WEBROOT"
  git pull --ff-only origin main
  test -f public/build/manifest.json
  mkdir -p "$WEBROOT/build" "$WEBROOT/css" "$WEBROOT/js"
  cp -R public/build/. "$WEBROOT/build/"
  cp public/css/*.css "$WEBROOT/css/"
  cp public/js/*.js "$WEBROOT/js/"
  "$PHP" artisan config:cache
  "$PHP" artisan view:cache
  echo "Versi terpasang:"
  git rev-parse --short HEAD
)
```

Langkah ini menyalin asset aplikasi, bukan .env, .htaccess, berkas unggahan, atau database. Jangan hanya menjalankan git pull: browser membaca asset dari webroot terpisah. Setelah selesai gunakan Ctrl+F5, lalu periksa Pengaturan, Aktivitas → Berita Daerah, dan daftar kiriman.

Pencarian alamat Google tetap memerlukan pembenahan izin Geocoding di Google Cloud. Pull kode tidak mengubah izin tersebut.
