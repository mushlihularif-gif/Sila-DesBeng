## Verifikasi yang dilakukan

- Keseluruhan suite lokal: **262 tes PHP, 4.280 assertion**, lulus dengan SQLite terisolasi dan memory_limit 512M. Angka ini mencakup keseluruhan aplikasi, bukan hanya perubahan tampilan.
- **25 tes JavaScript** lulus. Build Vite produksi berhasil; manifest dan CSS hasil build disertakan.
- Tes tambahan memeriksa penolakan penghapusan draf bukan pemilik/versi usang/status terkirim, cakupan kontribusi berita, penggunaan kembali bukti nomor, escaping ketentuan, dan bukti transfer API beserta buku transaksi.
- Template ruang berita dirender dengan data sintetis untuk warga, admin RT, admin RW, admin desa, super admin, dan staf. Ini tidak sama dengan menguji seluruh operasi setiap peran di produksi.
- Browser Chrome desktop 1360 px dan HP 390 px: editor berita, pengaturan, Aktivitas, serta editor ketentuan alat/kendaraan/fasilitas. Tidak ada error JavaScript atau overflow horizontal pada enam halaman ini.
- Permintaan AI berhasil/gagal disimulasikan untuk memeriksa animasi, hasil, dan pemulihan tombol. Pengujian ini tidak mengukur kualitas jawaban penyedia AI sungguhan.
- SDK Google nyata diuji pada HTML lokal dengan data sintetis: Alamat Saya, pesanan gas, alat, kendaraan, dan modal lokasi admin. Peta tampil, pemilihan koordinat mengisi field, alamat tersimpan dapat dipilih, alamat baru menghapus titik lama, dan peta tempat pengambilan tampil.
- Lokasi saya diuji memakai koordinat GPS simulasi browser. Tautan bagikan diuji pada tes JavaScript; penyelesaian berbagi melalui aplikasi WhatsApp/OS pengguna belum diuji.
- Pemeriksaan peta menggunakan intersepsi browser: origin mengikuti domain aplikasi untuk menguji pembatasan kunci, tetapi HTML dan asset berasal dari checkout lokal. Tidak ada pesanan/alamat/data warga produksi yang dibuat atau dihapus.

## Belum selesai / batas pemeriksaan

1. **Geocoding Google masih ditolak**: REQUEST_DENIED, "The webpage is not allowed to use the geocoder." Peta dan pemilihan titik tetap bekerja. Perlu memeriksa aktivasi Geocoding API serta pembatasan API/referrer pada proyek Google Cloud pemilik kunci. Penyebab konfigurasi persisnya belum diverifikasi melalui konsol Google.
2. Perubahan belum diterapkan ke cPanel pada saat audit lokal ini. Setelah pull, salin build, CSS dan JavaScript ke webroot terpisah, lalu cache ulang.
3. Login dan pengujian manual seluruh halaman seluruh peran di hosting belum dilakukan. Suite lokal mencakup regresi otorisasi, namun bukan bukti seluruh skenario produksi bebas kesalahan.
4. Pengiriman WhatsApp/push sungguhan, dialog berbagi OS, serta GPS perangkat nyata memerlukan pemeriksaan perangkat dan penyedia terkait.

Tidak ada perubahan algoritma KYC/AAD, migrasi database baru, atau penghapusan data produksi dalam paket ini. Kunci API dan .env tidak disertakan dalam commit.
